# NASA sources

**Our rule:** every number in the game comes from a source listed here. Where we simplify the science for gameplay, we say so.

The game reads its numbers from [`game/data/constants.json`](../game/data/constants.json); that file is the master copy from 9 November 2026 on. The team's working sheet is [`Moonbase_Commander_Final_Data.xlsx`](Moonbase_Commander_Final_Data.xlsx).

Value types: **NASA value** = straight from the source · **Measured value** = peer-reviewed measurement used where NASA has none · **NOAA value** = US government data used where NASA has no table · **Derived** = calculated from sourced values (formula given) · **Game setting / Game assumption** = our own choice to make the game playable, not a NASA number.

Simplifications we make on purpose: the habitat, life-support module, storm shelter, rover, drill and lamps are not counted as cargo; the storm doses for 5–15 g/cm² of shielding come from a pressurized-rover study and the 0 g/cm² dose from a habitat study (same NASA talk, same 1972 storm); one strong solar storm happens in every mission so players meet it (the real chance in 30 days is about 10 %).
