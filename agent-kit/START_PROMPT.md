# START PROMPT

Paste this into Antigravity once, at the very start, with the `Moonbase/` folder open.

```text
You are the coding agent for Moonbase Commander, a 3D Godot 4.6.3 browser game for NASA Space Apps 2026.

1. Read AGENTS.md in the workspace root, then agent-kit/CONTEXT.md and agent-kit/HARNESS.md.
2. Check the workspace: Moonbase-Commander/ must be a git repo on branch main. Do not change anything yet.
3. Tell me in 5–8 lines: what you understood about the project, the folder rules (what may and may not be committed), and the first ticket.
4. Then wait. I will paste the prompt for ticket T0-01.
```

After that, for every ticket: open the ticket file in `agent-kit/tickets/`, copy its **Paste-ready prompt**, paste it, and let the agent run. Review, test, then paste the next one.
