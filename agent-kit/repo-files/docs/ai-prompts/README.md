# AI prompts

NASA Space Apps asks teams to show the AI tools they used, with the prompts and reasoning behind them.

We built the game with a coding agent (Antigravity, with Godot MCP), one small task ("ticket") at a time. For every ticket, this folder has one file with:

- the exact prompt we gave the agent,
- what the agent changed,
- how we checked it (tests, balance scenarios, web export, phone test),
- what we did ourselves.

The full list of AI use is in [../ai-usage.md](../ai-usage.md). The asset packs (3D models, sounds, fonts, NASA maps) were downloaded by hand; organizing and importing them into the project was an agent task (see PA-02).
